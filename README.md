# CSS-свойства во втором проекте, которых нет в первом

Сравнение сделано по всем CSS-файлам репозиториев [«Оно тебе надо»](https://github.com/Alexey-UI/ono-tebe-nado-ad/tree/597b40589dfcb1ffe5199014b7329cd3c7881c50) и [«Посмотри в окно»](https://github.com/Alexey-UI/posmotri-v-okno-ad/tree/a19e7b55f070cea45fb07b4f7b14b4f8fc8438d7). Ниже — **25 названий свойств**, встречающихся во втором проекте и отсутствующих в первом. Примеры взяты из [`styles/style.css`](https://github.com/Alexey-UI/posmotri-v-okno-ad/blob/a19e7b55f070cea45fb07b4f7b14b4f8fc8438d7/styles/style.css) и [`styles/preloader.css`](https://github.com/Alexey-UI/posmotri-v-okno-ad/blob/a19e7b55f070cea45fb07b4f7b14b4f8fc8438d7/styles/preloader.css).

## Логические размеры, отступы и рамки

«По строке» (`inline`) и «по блоку» (`block`) — направления, зависящие от режима письма. Для обычного горизонтального русского текста первое соответствует ширине или горизонтальным сторонам, второе — высоте или вертикальным сторонам.

| Свойство | Что делает | Пример из проекта |
| --- | --- | --- |
| `inline-size` | Задаёт размер по строке: здесь фактически ширину элемента. | `.result { inline-size: 711px; }` |
| `block-size` | Задаёт размер по блоку: здесь фактически высоту элемента. | `.result__video-container { block-size: 386px; }` |
| `min-inline-size` | Ограничивает минимальный размер по строке. Значение `0` разрешает Flex-элементу сжиматься настолько, чтобы длинный текст не раздвигал колонку. | `.content__details { min-inline-size: 0; }` |
| `min-block-size` | Ограничивает минимальный размер по блоку: кнопка не станет ниже указанного значения. | `.more-button { min-block-size: 34px; }` |
| `margin-block-end` | Создаёт внешний отступ в конце блока; здесь — снизу. | `.result__video-container { margin-block-end: 16px; }` |
| `padding-inline` | Задаёт внутренние отступы с обеих сторон по строке; здесь — слева и справа. | `.content__list-item { padding-inline: 3px; }` |
| `border-inline` | Задаёт рамки с обеих сторон по строке. Значение `none` убирает боковые рамки поля, оставляя верхнюю и нижнюю рамки, заданные через `border`. | `.search-form__textfield { border-inline: none; }` |

## Flex-раскладка

| Свойство | Что делает | Пример из проекта |
| --- | --- | --- |
| `flex-grow` | Определяет, какую долю свободного места может занять Flex-элемент. Значение `1` даёт правой колонке занять доступное пространство. | `.content__details { flex-grow: 1; }` |
| `align-self` | Меняет выравнивание отдельного Flex-элемента по поперечной оси, переопределяя `align-items` контейнера. | `.search-form__submit-button { align-self: flex-end; }` |

## Прокрутка и длинный текст

| Свойство | Что делает | Пример из проекта |
| --- | --- | --- |
| `overflow` | Управляет содержимым, которое выходит за границы элемента. `hidden` скрывает выступающую часть. | `.content__video-card-title { overflow: hidden; }` |
| `overflow-y` | Управляет переполнением по вертикали. `auto` показывает вертикальную прокрутку, когда содержимое не помещается. | `.content__list-container { overflow-y: auto; }` |
| `text-overflow` | Задаёт обозначение обрезанного текста. `ellipsis` показывает многоточие; в заголовке работает вместе с `overflow: hidden` и `white-space: nowrap`. | `.content__video-card-title { text-overflow: ellipsis; }` |
| `white-space` | Управляет переносом и обработкой пробелов. `nowrap` запрещает перенос строк. | `.content__video-card-title { white-space: nowrap; }` |
| `-webkit-line-clamp` | Ограничивает число видимых строк текста; здесь описание карточки обрезается после двух строк. | `.content__video-card-description { -webkit-line-clamp: 2; }` |
| `-webkit-box-orient` | Задаёт направление старой WebKit-модели коробки. В сочетании с `display: -webkit-box` и `-webkit-line-clamp` позволяет обрезать многострочный текст. | `.content__video-card-description { -webkit-box-orient: vertical; }` |

Два последних свойства имеют префикс `-webkit-`; для эффекта ограничения строк здесь также нужны `display: -webkit-box` и `overflow: hidden`.

## Форма и видимые состояния

| Свойство | Что делает | Пример из проекта |
| --- | --- | --- |
| `outline` | Рисует обводку элемента, не меняя размеры раскладки. Здесь она обозначает фокус при навигации с клавиатуры. | `.button:focus-visible { outline: 1px solid #fff; }` |
| `outline-offset` | Сдвигает обводку наружу или внутрь относительно края элемента. | `.button:focus-visible { outline-offset: 2px; }` |
| `appearance` | Управляет встроенным оформлением элемента браузером. `none` убирает стандартный внешний вид текстового поля. | `.search-form__textfield { appearance: none; }` |
| `content` | Создаёт содержимое псевдоэлемента `::before` или `::after`. Пустая строка создаёт здесь псевдоэлемент для заливки чекбокса. | `.search-form__pseudo-checkbox::after { content: ''; }` |
| `opacity` | Задаёт прозрачность от `0` (невидимо) до `1` (полностью видно). Здесь заливка чекбокса появляется при выборе. | `.search-form__checkbox:checked + .search-form__pseudo-checkbox::after { opacity: 1; }` |

## Видео, изображения и скрытие

| Свойство | Что делает | Пример из проекта |
| --- | --- | --- |
| `object-position` | Определяет положение видео или изображения внутри своей области, когда используется, например, `object-fit: cover`. | `.result__video { object-position: center; }` |
| `clip` | Старый способ прямоугольной обрезки абсолютно позиционированного элемента. Здесь участвует в визуальном скрытии обычного чекбокса. | `.visually-hidden { clip: rect(0 0 0 0); }` |
| `clip-path` | Обрезает видимую часть элемента по заданной форме. `inset(50%)` скрывает её в том же классе. | `.visually-hidden { clip-path: inset(50%); }` |

`clip` считается устаревшим свойством; в этом коде оно соседствует с `clip-path`. Визуально скрытый чекбокс при этом остаётся в документе и может получать фокус.

## Анимация прелоадера

| Свойство | Что делает | Пример из проекта |
| --- | --- | --- |
| `animation` | Краткая запись параметров анимации: имени, длительности, повторения и других настроек. Здесь `focusfade` длится `2.8s` и повторяется бесконечно. | `.square { animation: focusfade 2.8s infinite; }` |
| `animation-delay` | Откладывает начало анимации конкретного элемента. Разные задержки заставляют квадраты двигаться не одновременно. | `.square:nth-child(2) { animation-delay: 0.7s; }` |

**Происхождение кода:** `animation` и `animation-delay` находятся в стартовом `preloader.css`, который не менялся при оформлении проекта. `inline-size` и `block-size` уже встречались в стартовом `style.css`, но также использованы в добавленных стилях. Список сравнивает итоговые CSS-файлы, а не только изменения в коммитах.
